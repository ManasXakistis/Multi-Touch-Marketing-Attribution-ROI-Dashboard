Day 1 Data connection and model setup Power Query + DAX
1Get Data → Text/CSV → load marketing_campaign_performance_10000.csv (10,000 rows, 11 columns)
2In Power Query: change StartDate and EndDate to Date type (format DD-MM-YYYY); add custom column Duration = EndDate − StartDate
3Set Channel as a dimension and all numeric columns (Impressions, Clicks, Leads, Conversions, Cost_USD, Revenue_USD, ROI) as measures
4Create 5 DAX measures: CTR = Clicks/Impressions · Lead Rate = Leads/Clicks · Conv Rate = Conversions/Leads · CPA = Cost_USD/Conversions · Avg ROI = AVERAGE(ROI)
5Add a Month column from StartDate for timeline slicing
Output: clean model with 5 measures ready for visuals
